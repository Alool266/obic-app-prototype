1. Goal

Build one mobile app for iOS and Android so international clients can discover, request, track, and communicate about OBIC China corporate/travel services — look & density inspired by Ctrip (携程) Chinese app, branded as OBIC. Arabic is the main/default language with full RTL; English available via in-app switch. Designed & developed by Ali.

10. Security & no data leak

  • Private git only · never commit .env / keys / customer PII
  • Keep Desktop deal/PRD/staff files out of the repo
  • Dev / Staging / Prod environments separated
  • Password hashing, OTP rate limits, HTTPS, admin audit log
  • App Store privacy policy required before release

11. How to use deliverables

  1. Open prototype/index.html in Chrome — click left nav or in-phone tabs
  2. Remote share: publish static site via GitHub Pages (repo root) — stakeholder opens a URL on phone or desktop
  3. Share this PDF with stakeholders for sign-off on V1 scope
  4. After approval: scaffold Flutter or Expo app and implement screens matching the prototype

12. Fastest path to real iOS/Android code

  1. Choose stack: Flutter (fast UI) or Expo (JS team)
  2. Scaffold app + navigation with 5 tabs matching prototype
  3. Hard-code services list first; plug API in week 2
  4. Stand up Nest/Laravel + Postgres (users, services, orders, branches)
  5. Wire auth OTP; then order submit; then chat stub
  6. Internal TestFlight / APK — do not block on Figma (HTML is the UX source)
